Abstrak

Praktikum ini bertujuan mengimplementasikan aplikasi pencatat keuangan pribadi berbasis Flutter dengan bahasa pemrograman Dart. Aplikasi terdiri atas tiga halaman, yaitu dasbor, formulir pencatatan transaksi, dan rincian transaksi, yang didukung model data Transaction. Fitur utama meliputi perhitungan saldo dinamis, pemformatan mata uang Rupiah, validasi formulir, pemilihan tanggal, penyaringan berdasarkan jenis dan kategori, serta pengurutan berdasarkan tanggal dan nominal. Pengujian skenario menunjukkan bahwa seluruh fungsi berjalan sesuai spesifikasi: dari enam transaksi uji, saldo akhir yang dihasilkan sebesar Rp 8.186.000, sejalan dengan perhitungan manual. Praktikum membuktikan bahwa pengelolaan state dengan StatefulWidget dan setState memadai untuk aplikasi berskala kecil.

Kata kunci: Flutter, Dart, state management, validasi formulir, aplikasi keuangan.

BAB II. LANDASAN TEORI

Flutter dan Dart. Flutter membangun antarmuka sebagai pohon widget yang bersifat deklaratif; setiap perubahan state memicu pembangunan ulang bagian pohon yang terdampak. Dart merupakan bahasa berorientasi objek dengan sistem tipe yang aman terhadap null (sound null safety).

StatelessWidget dan StatefulWidget. StatelessWidget tidak menyimpan keadaan yang berubah, sedangkan StatefulWidget memiliki objek State yang diperbarui melalui setState() sehingga build() dipanggil ulang.

Navigator. Navigasi berbasis tumpukan (stack) dilakukan dengan push untuk membuka halaman dan pop untuk kembali; pop dapat membawa nilai balik yang diterima oleh pemanggil melalui await.

Form dan Validasi. Widget Form dengan GlobalKey<FormState> memungkinkan pemanggilan validate() terhadap seluruh TextFormField sekaligus.

3.4 Halaman Dashboard (StatefulWidget)

Halaman ini mengelola state berupa daftar transaksi, filter jenis, filter kategori, dan kriteria pengurutan. Saldo dihitung melalui getter currentBalance (saldo awal Rp 5.000.000 ditambah pemasukan dan dikurangi pengeluaran). Getter filteredTransactions menerapkan tiga tahap berurutan: penyaringan jenis, penyaringan kategori, dan pengurutan (tanggal terbaru, nominal terkecil, nominal terbesar). Fungsi formatRupiah() menyisipkan pemisah ribuan secara iteratif dari digit paling kanan. Filter dan pengurutan disajikan melalui showModalBottomSheet; StatefulBuilder digunakan agar pilihan sementara dapat diperbarui tanpa membangun ulang seluruh halaman sebelum tombol “Terapkan” ditekan. Navigasi ke halaman tambah dan detail memanfaatkan Navigator.push, dengan objek Transaction dikembalikan melalui Navigator.pop.

  String formatRupiah(int value) {
    final bool negative = value < 0;

    final String number =
        value.abs().toString();

    String result = '';
    int counter = 0;

    for (int i = number.length - 1;
        i >= 0;
        i--) {
      result = number[i] + result;
      counter++;

      if (counter == 3 && i != 0) {
        result = '.$result';
        counter = 0;
      }
    }

    return '${negative ? '-' : ''}Rp $result';

      result = result
          .where(

                !transaction.isIncome,

      result.sort(

      );

    if (selectedSort ==

      result.sort(

    }

    if (selectedSort ==
        'Nominal terbesar') {
      result.sort(
        (a, b) =>

3.5 Halaman Tambah Transaksi

Halaman ini memakai Form dengan GlobalKey<FormState> untuk validasi. Terdapat tiga TextEditingController (judul, nominal, tanggal) yang dibebaskan pada dispose() guna mencegah kebocoran memori. Input nominal diformat otomatis dengan pemisah ribuan pada setiap perubahan teks (_formatAmount) dan dikonversi kembali ke bilangan bulat melalui parseAmount berbasis ekspresi reguler [^0-9]. Tanggal dipilih menggunakan showDatePicker pada rentang 2020–2030. Validator memastikan judul tidak kosong, nominal lebih dari nol, dan tanggal telah dipilih.

  String formatRupiah(int value) {
    if (value == 0) {
      return '0';
    }

    final String number = value.toString();

    String result = '';
    int counter = 0;

    for (int i = number.length - 1; i >= 0; i--) {
      result = number[i] + result;
      counter++;

      if (counter == 3 && i != 0) {
        result = '.$result';
        counter = 0;
      }
    }

    return result;
  }

  int parseAmount(String value) {
    final cleanValue =
        value.replaceAll(RegExp(r'[^0-9]'), '');

    if (cleanValue.isEmpty) {
      return 0;
    }

    return int.parse(cleanValue);
  }

  void _formatAmount() {
    final amount =
        parseAmount(_amountController.text);

    final formatted =
        formatRupiah(amount);

    _amountController.value =
        TextEditingValue(
      text: formatted,
      selection: TextSelection.collapsed(
        offset: formatted.length,
      ),
    );
  }

  Future<void> _selectDate() async {
    final picked = await showDatePicker(
      context: context,
      initialDate:
          selectedDate ?? DateTime.now(),
      firstDate: DateTime(2020),
      lastDate: DateTime(2030),
    );

    if (picked != null) {
      setState(() {
        selectedDate = picked;

        _dateController.text =
            '${picked.day.toString().padLeft(2, '0')}/'
            '${picked.month.toString().padLeft(2, '0')}/'
            '${picked.year}';
      });
    }
  }

  void _saveTransaction() {
    if (!_formKey.currentState!.validate()) {
      return;

    final amount =
        parseAmount(_amountController.text);

    final transaction = Transaction(
      title: _titleController.text,
      amount: amount,
      isIncome:
          transactionType == 'Pemasukan',
      category: selectedCategory,
      date: selectedDate!,
    );

    Navigator.pop(
      context,
      transaction,
    );
  }

class TransactionDetailScreen
    extends StatelessWidget {
  final Transaction transaction;

  const TransactionDetailScreen({
    super.key,

  String formatRupiah(int value) {
    final number =
        value.toString();

    String result = '';
    int counter = 0;

    for (int i = number.length - 1;
        i >= 0;
        i--) {
      result =
          number[i] + result;

      counter++;

      if (counter == 3 &&
          i != 0) {
        result =
            '.$result';

        counter = 0;
      }
    }

    return 'Rp $result';
  }

        '${date.month.toString().padLeft(2, '0')}/'

4.4 Pembahasan

Hasil pengujian menunjukkan bahwa seluruh fungsi inti berjalan sesuai rancangan. Perhitungan saldo konsisten dengan verifikasi manual, dan penyaringan bertahap (jenis, kategori, lalu pengurutan) menghasilkan daftar yang tepat pada setiap kombinasi. Penyalinan daftar dengan List.from(transactions) sebelum penyaringan menjaga data asli tetap utuh sehingga pengurutan tidak mengubah urutan penyimpanan.

Pengembalian objek melalui Navigator.pop dan penerimaan melalui await Navigator.push terbukti memisahkan tanggung jawab antarhalaman: halaman formulir hanya membentuk objek, sedangkan state daftar tetap dimiliki dasbor. Validasi formulir mencegah data tidak valid (judul kosong, nominal nol, tanggal belum dipilih), sehingga operasi selectedDate! pada _saveTransaction aman dijalankan.

Beberapa keterbatasan teridentifikasi. Pertama, data hanya tersimpan di memori sehingga hilang saat aplikasi ditutup; penyimpanan persisten (misalnya SQLite atau shared_preferences) diperlukan. Kedua, fungsi formatRupiah terduplikasi pada tiga berkas dan sebaiknya diekstraksi menjadi utilitas bersama atau memakai paket intl (NumberFormat). Ketiga, nama pengguna ("Budi") dan saldo awal ditulis langsung (hard-coded). Keempat, pengelolaan state dengan setState kurang skalabel untuk aplikasi yang lebih besar, sehingga solusi seperti Provider atau Riverpod lebih sesuai. Terakhir, parameter initialValue pada DropdownButtonFormField membutuhkan versi Flutter terbaru; pada versi lama digunakan value.
