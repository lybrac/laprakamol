II. Dasar Teori

Flutter menyediakan dua widget utama untuk menerima input teks dari pengguna, yaitu TextField dan TextFormField.. TextField digunakan untuk input teks sederhana tanpa validasi bawaan, sedangkan TextFormField dirancang untuk digunakan di dalam widget Form karena memiliki parameter validator yang memudahkan proses validasi data sebelum diproses lebih lanjut..

Widget Form bekerja bersama GlobalKey<FormState> untuk mengelola seluruh TextFormField di dalamnya secara terpusat.. Dengan memanggil method validate() pada FormState, seluruh validator pada setiap field akan dijalankan sekaligus, sehingga aplikasi dapat menampilkan pesan kesalahan apabila data yang dimasukkan tidak sesuai..

TextEditingController digunakan untuk membaca, mengatur, dan memantau nilai yang ada pada sebuah field input secara programatik.. Controller ini wajib di-dispose pada method dispose() untuk mencegah kebocoran memori (memory leak)..

A. Basic Form dengan TextFormField dan Validasi.

Pada latihan ini dibuat form input Nama dan Email menggunakan TextFormField di dalam widget Form.. Validasi dilakukan melalui parameter validator pada masing-masing field: field Nama akan menampilkan pesan kesalahan apabila dikosongkan, sedangkan field Email akan menampilkan pesan kesalahan apabila kosong atau tidak mengandung karakter '@'.. Saat tombol Submit ditekan, method _submitForm() akan memanggil _formKey.currentState!.validate() untuk menjalankan seluruh validator; jika semua data valid, hasil input ditampilkan melalui SnackBar..

import 'package:flutter/material.dart';
 
void main() => runApp(const MyApp());
 
class MyApp extends StatelessWidget {
  const MyApp({super.key});
  // 2411532017
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          title: const Text("Basic Form TextFormField"),
        ),
        body: const MyFormText(),
      ),
    );
  }
}
 
class MyFormText extends StatefulWidget {
  const MyFormText({super.key});
 
  @override
  State<MyFormText> createState() => _MyFormTextState();
}
 
class _MyFormTextState extends State<MyFormText> {
  final _formKey = GlobalKey<FormState>();
  final _nameController = TextEditingController();
  final _emailController = TextEditingController();
 
  @override
  void dispose() {
    _nameController.dispose();
    _emailController.dispose();
    super.dispose();
  }
 
  void _submitForm() {
    if (_formKey.currentState!.validate()) {
      String name = _nameController.text;
      String email = _emailController.text;
 
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Validasi $name, $email Berhasil')),
      );
    }
  }
 
  @override
  Widget build(BuildContext context) {
    return Form(
      key: _formKey,
      child: Padding(
        padding: const EdgeInsets.all(20.0),
        child: Column(
          mainAxisAlignment: MainAxisAlignment.start,
          children: [
            const SizedBox(height: 10),
            TextFormField(
              controller: _nameController,
              decoration: const InputDecoration(
                labelText: "Nama : ",
                border: OutlineInputBorder(),
              ),
              validator: (value) {
                if (value == null || value.isEmpty) {
                  return 'Masukkan nama anda';
                }
                return null;
              },
            ),
            const SizedBox(height: 10),
            TextFormField(
              controller: _emailController,
              decoration: const InputDecoration(
                labelText: "Email : ",
                border: OutlineInputBorder(),
              ),
              validator: (value) {
                if (value == null || value.isEmpty) {
                  return 'Masukkan email anda';
                }
                if (!value.contains('@')) {
                  return 'Email tidak valid';
                }
                return null;
              },
            ),
            const SizedBox(height: 10),
            SizedBox(
              width: double.infinity,
              child: ElevatedButton(
                onPressed: _submitForm,
                child: const Text('Submit'),
              ),
            ),
          ],
        ),
      ),
    );
  }
}.

C. Studi Kasus: Kalkulator Kabataku.

Studi kasus ini mengimplementasikan kalkulator sederhana dengan dua field input angka (Angka 1 dan Angka 2) serta empat tombol operasi: Tambah, Kurang, Kali, dan Bagi.. Method _hitung() mengubah teks input menjadi tipe double menggunakan double.tryParse(); apabila salah satu input tidak valid, ditampilkan pesan 'Masukkan angka yang valid!'.. Untuk operasi pembagian, program memeriksa terlebih dahulu apakah pembagi bernilai 0 agar tidak terjadi error pembagian oleh nol.. Hasil perhitungan ditampilkan pada bagian bawah layar dalam format 'a simbol b = hasil'..

import 'package:flutter/material.dart';
 
void main() => runApp(const MyApp());
 
class MyApp extends StatelessWidget {
  const MyApp({super.key});
  // 2411532017
  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      home: Scaffold(
        appBar: AppBar(
          title: const Text('Kalkulator Kabataku'),
        ),
        body: const KalkulatorForm(),
      ),
    );
  }
}
// 2411532017
 
class KalkulatorForm extends StatefulWidget {
  const KalkulatorForm({super.key});
 
  @override
  State<KalkulatorForm> createState() => _KalkulatorFormState();
}
// 2411532017
 
class _KalkulatorFormState extends State<KalkulatorForm> {
  final TextEditingController _angka1Controller = TextEditingController();
  final TextEditingController _angka2Controller = TextEditingController();
 
  String _hasil = '';
 
  @override
  void dispose() {
    _angka1Controller.dispose();
    _angka2Controller.dispose();
    super.dispose();
  }
 
  void _hitung(String operasi) {
    double? a = double.tryParse(_angka1Controller.text);
    double? b = double.tryParse(_angka2Controller.text);
 
    if (a == null || b == null) {
      setState(() {
        _hasil = 'Masukkan angka yang valid!';
      });
      return;
    }
 
    double result = 0;
    String simbol = '';
 
    switch (operasi) {
      case 'tambah':
        result = a + b;
        simbol = '+';
        break;
      case 'kurang':
        result = a - b;
        simbol = '-';
        break;
      case 'kali':
        result = a * b;
        simbol = 'x';
        break;
      case 'bagi':
        if (b == 0) {
          setState(() {
            _hasil = 'Tidak bisa dibagi 0!';
          });
          return;
        }
        result = a / b;
        simbol = ':';
        break;
    }
 
    setState(() {
      _hasil = '$a $simbol $b = $result';
    });
  }
 
  @override
  Widget build(BuildContext context) {
    return Padding(
      padding: const EdgeInsets.all(20.0),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          const Text('Angka 1 :'),
          const SizedBox(height: 8),
          TextField(
            controller: _angka1Controller,
            keyboardType: const TextInputType.numberWithOptions(decimal: true),
            decoration: const InputDecoration(
              border: OutlineInputBorder(),
              hintText: 'Masukkan angka pertama',
            ),
          ),
          const SizedBox(height: 16),
          const Text('Angka 2 :'),
          const SizedBox(height: 8),
          TextField(
            controller: _angka2Controller,
            keyboardType: const TextInputType.numberWithOptions(decimal: true),
            decoration: const InputDecoration(
              border: OutlineInputBorder(),
              hintText: 'Masukkan angka kedua',
            ),
          ),
          const SizedBox(height: 20),
          Row(
            mainAxisAlignment: MainAxisAlignment.spaceBetween,
            children: [
              ElevatedButton(
                onPressed: () => _hitung('kali'),
                child: const Text('Kali (x)'),
              ),
              ElevatedButton(
                onPressed: () => _hitung('bagi'),
                child: const Text('Bagi (:)'),
              ),
              ElevatedButton(
                onPressed: () => _hitung('tambah'),
                child: const Text('Tambah (+)'),
              ),
              ElevatedButton(
                onPressed: () => _hitung('kurang'),
                child: const Text('Kurang (-)'),
              ),
            ],
          ),
          const SizedBox(height: 24),
          Text(
            'Hasil : $_hasil',
            style: const TextStyle(fontSize: 18, fontWeight: FontWeight.bold),
          ),
        ],
      ),
    );
  }
}.

V. Pembahasan.

Dari ketiga latihan di atas terlihat perbedaan mendasar antara TextField dan TextFormField.. TextFormField lebih tepat digunakan ketika data input memerlukan validasi sebelum diproses, seperti pada latihan A, karena terintegrasi langsung dengan widget Form dan GlobalKey<FormState>.. Sebaliknya, TextField pada latihan B lebih sederhana dan cocok digunakan ketika validasi tidak diperlukan, namun tetap membutuhkan pemantauan nilai secara real-time melalui onChanged..

Pada studi kasus kalkulator, penanganan kesalahan (error handling) menjadi aspek penting, baik untuk memastikan input berupa angka yang valid maupun untuk mencegah pembagian oleh nol.. Penggunaan setState() pada setiap perubahan hasil perhitungan memastikan antarmuka pengguna selalu diperbarui sesuai dengan data terbaru..

VI. Kesimpulan.

  • TextFormField beserta Form dan GlobalKey<FormState> memudahkan penerapan validasi input secara terpusat..
  • TextEditingController berperan penting dalam mengambil, memantau, dan mengelola nilai input, serta wajib di-dispose untuk mencegah kebocoran memori..
  • Event handling seperti onChanged dan onPressed memungkinkan aplikasi merespons interaksi pengguna secara langsung..
  • Studi kasus kalkulator menunjukkan penerapan logika kondisional, penanganan error, dan pembaruan tampilan (setState) secara bersamaan dalam satu aplikasi Flutter sederhana..
